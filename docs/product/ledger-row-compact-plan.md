# 明細列緊湊化計畫（Phase 2）

狀態：**計畫，尚未實作**（分支 `feature/ledger-row-compact`，預期獨立 PR）。本文件為[版面重構計畫](navigation-restructure-plan.md)中明細頁（Phase 2）的拆分細節。

---

## 1. 目標

- 明細頁（現 `/ledger`）每筆紀錄**不得超過兩行**，最終收斂為**固定一行（已定案）**。
- 顯示**所有紀錄**：官方確認紀錄為主，草稿待審、掃描來源另外分區（沿用目前 Review queue 分法）。
- 每列高度固定；空狀態保留。

## 2. 單列內容（已定案）

- 一行內容：對象/名稱（左）+ 金額（右），其餘資訊（日期 · 帳戶 · 類別 · 狀態）以次要文字緊湊顯示，長內容 ellipsis 截斷。
- 動作只留**圖示**，同一行三個：修改（鉛筆）、刪除（垃圾桶）、**更多（⋯）**。
- 「⋯」展開顯示情境相關的次要動作：復發控制（暫停/取消復發，僅復發型紀錄）、補齊資料（僅缺漏支出）；與編輯、刪除保持同一行。
- **刪除行為由設定決定（已定案）**：預設**作廢**（保留歷史、不計入餘額/報表），可在設定改為**真正刪除**（紀錄直接移除）——開關本身在[設定分區計畫](settings-restructure-plan.md)落地，本階段負責明細列的刪除動作依設定執行。

## 3. 中長期（不在本階段）

月份、帳戶、類別、類型篩選與搜尋（產品需求「Search is a core ledger feature」）。

## 4. 影響範圍

| 檔案 | 預期變動 |
|---|---|
| `src/App.tsx` | `LedgerRecordCard` 壓成一行三圖示；動作收進「⋯」溢位選單；刪除行為讀設定（localStorage） |
| `src/styles.css` | 明細列列高收斂、動作圖示、溢位選單樣式 |
| `src/App.test.tsx`、`tests/e2e/app-shell.spec.ts` | 明細列選擇器與動作測試更新 |

## 5. 已定案

- 明細列固定一行，同一行三個圖示：修改、刪除、更多（⋯，展開復發控制與補齊資料）。
- 刪除行為可設定：預設作廢，可在設定改為真正刪除。

## 6. 驗證

`npm run typecheck`、`npm test`、`npm run build`、`npm run test:e2e`；窄螢幕（320/390px）無水平溢出、明細列不高於兩行。
